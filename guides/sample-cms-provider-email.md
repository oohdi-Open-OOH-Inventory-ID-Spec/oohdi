# Sample Email to a CMS Provider

Subject: Request to Expose Screen Inventory via OOHDI-Compatible Registry

Dear [CMS Provider / Account Team],

I am writing to request that [Company Name] be able to expose our screen inventory through an OOHDI-compatible screen registry and that our inventory data be made available through the platform you currently provide for our digital screens.

We are looking to ensure our inventory can be discovered, validated, and referenced in a standard way across industry partners, ad-tech systems, and registry consumers. We believe this is aligned with the direction of the OOHDI model and will improve interoperability and transparency for screen inventory.

At a high level, we need the following:

- a public, read-only registry or registry integration for our inventory
- authoritative namespace declaration for our media owner domain
- canonical screen identifiers for each display or unit
- inventory metadata exposed via public OOHDI-compatible endpoints
- support for standard status handling such as active, inactive, planned, and decommissioned records

In practical terms, we would like to work with you to confirm whether your system can:

- publish a screen registry record for each digital or static inventory unit
- expose inventory metadata in a standards-based JSON format
- support canonical IDs that are stable and attributable to our media owner namespace
- maintain records for additions, removals, location changes, and replacements
- expose the inventory data through an authoritative registry accessible to external clients

If your platform already supports registry integration or can add this capability, we would appreciate a technical review of the requirements and a proposed implementation plan.

If this is not currently in scope, we would still like to understand the best path forward for making our inventory discoverable through an OOHDI-compatible registry model.

Please let us know:

- whether your system can support this
- whether this requires a product, API, or integration change
- what data fields and identifiers would need to be exposed
- what timeline would be realistic for implementation

Thank you for your time and consideration. We appreciate the partnership and look forward to discussing how we can align our inventory data with a standards-based registry approach.

Best regards,

[Your Name]
[Title]
[Company Name]
[Email Address]
[Phone Number]
