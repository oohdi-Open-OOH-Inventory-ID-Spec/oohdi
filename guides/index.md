# OOHDI Guides

This index lists the reference guides and implementation notes available in this repository for media owners, registry operators, and implementation teams.

## Guides

- [Guide for Agent Registry Builders](guide-for-agent-registry-builders.md)  
  A practical implementation guide for coding agents and developers working with a third-party company that wants to add OOHDI-compatible registry endpoints to an existing platform.

- [Media Owner Setup Guide](media-owner-setup-guide.md)  
  Explains how a media owner can establish its namespace, declare an authoritative registry, and prepare the public metadata needed for OOHDI discovery.

- [Registry Setup Guide](registry-setup-guide.md)  
  Covers the operational requirements for building a public OOHDI registry, including DNS authority, endpoint behavior, JSON schema, and registry responsibilities.

- [Registry Quickstart](registry-quickstart.md)  
  A short, implementation-focused checklist for getting a minimal OOHDI-compatible registry running quickly.

- [Sample Email to a CMS Provider](sample-cms-provider-email.md)  
  A ready-to-use outreach template for asking a CMS or inventory platform provider to support OOHDI-compatible registry exposure.
